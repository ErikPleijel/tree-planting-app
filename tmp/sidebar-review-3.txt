===== "Add New Location" uniqueness check (before removing the dashboard's copy) =====
Grepped the whole resources/views tree for `planting-locations.create` — it
appears in exactly two files: dashboard.blade.php (the grid being removed)
and resources/views/planting-locations/index.blade.php:6-8, which has its
own, independent, unconditional "Add New Location" button:

    <div class="text-right mb-4">
        <a href="{{ route('planting-locations.create') }}"
           class="bg-primary text-white px-6 py-3 rounded-lg hover:bg-green-700 transition-colors">
            Add New Location
        </a>
    </div>

This button is not role-gated in the view itself (the whole planting-locations
route group is already gated at the route level to Admin|SuperAdmin|Monitor|
Grower, same roles the dashboard button was scoped to via @role(...)), and it
does not depend on anything the dashboard grid provided. So removing the
dashboard's "Add New Location" shortcut causes no functionality loss —
planting-locations.create remains reachable from the Locations index page
for the same set of roles. Proceeded with the removal; did not stop for a
decision.
